Capítulo 01

Conceptos Clave

Fine-tuning, LoRA, PEFT, y métricas de evaluación.

1. ¿Qué es Fine-Tuning?

Fine-tuning es el proceso de adaptar un modelo de lenguaje preentrenado a un caso de uso específico, mejorando su precisión y relevancia. Se realiza mediante el ajuste de los pesos del modelo con datos específicos.

2. Principios fundamentales

  • Adaptación: ajustar el modelo a casos de uso específicos.
  • Optimización: usar técnicas como LoRA y PEFT para mejorar el rendimiento.
  • Evaluación: medir la precisión y relevancia del modelo.

Capítulo 04

Pipeline de Fine-Tuning

Implementación del pipeline de fine-tuning.

1. Pasos del Pipeline

  1. Preparación de Datos: recolección y limpieza de datos.
  2. Configuración del Modelo: carga del modelo preentrenado.
  3. Fine-Tuning: ajuste de pesos con datos específicos.
  4. Evaluación: medición de métricas de rendimiento.

2. Ejemplo de Código

Python 
from transformers import AutoModelForSequenceClassification, AutoTokenizer, Trainer, TrainingArguments

# Cargar modelo y tokenizer
model_name = "bert-base-uncased"
model = AutoModelForSequenceClassification.from_pretrained(model_name, num_labels=2)
tokenizer = AutoTokenizer.from_pretrained(model_name)

# Configuración del entrenamiento
training_args = TrainingArguments(
    output_dir="./results",
    per_device_train_batch_size=8,
    num_train_epochs=3,
    save_steps=10_000,
    save_total_limit=2,
)

# Entrenamiento
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=train_dataset,
    eval_dataset=eval_dataset,
)

# Fine-tuning
trainer.train()

Capítulo 05

Evaluación

Métricas de evaluación y validación del modelo.

1. Métricas Clave

  • Precisión: porcentaje de respuestas correctas.
  • Recall: capacidad de identificar todos los casos positivos.
  • F1-Score: media armónica de precisión y recall.

2. Validación del Modelo

La validación del modelo se realiza mediante la evaluación de métricas en un conjunto de datos de prueba. Esto permite medir la precisión y relevancia del modelo en casos de uso reales.
